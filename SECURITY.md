# Public Repository Boundary

This repository is a sanitized portfolio artifact and contains documentation only.

Do not add:

- production source code or copied internal snippets;
- customer, participant or employee information;
- real scenarios, transcripts or evaluation results;
- organization names, logos or screenshots from internal systems;
- API keys, tokens, endpoints or `.env` files;
- prompts, scoring rules, deployment settings or infrastructure details;
- internal documents, issue links or repository references.

Before every public update, review the staged files and scan them for secrets and personal information.

Commit metadata is also public. Use the intended public GitHub identity and a GitHub-provided `noreply` address when a personal e-mail address should remain private.
